# User Request

> for "decloud status" command, can we have a no parameters variant that would list all the registered services with their statuses?

## Date

2026-05-12

## Slug

`status-list-all-services`

## Notes

The user wants the `decloud status` command, when invoked without any service
name argument, to list every registered service together with its current
status (rather than requiring a service name and producing a focused report
for that single service).
